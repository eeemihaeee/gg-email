# Руководство пользователя

## Первый запуск

1. Запустите **GG Email** из меню «Пуск».
2. Введите рабочий адрес почты (например, `i.petrov@company.ru`) и нажмите «Продолжить».
   Если администратор настроил автонастройку, серверы подставятся автоматически.
3. Введите пароль (для Gmail и Яндекса — пароль приложения; если администратор
   настроил OAuth, нажмите «Войти»).
4. Нажмите «Проверить подключение», затем «Сохранить».

Письма начнут загружаться сразу: сначала последние 200 на папку, остальные —
по мере прокрутки. Заголовки хранятся локально, поэтому список открывается мгновенно.

## Интерфейс

| Область | Что делает |
|---|---|
| Слева | «Все входящие», учётные записи (цветная точка), папки, настройки |
| В центре | список писем выбранной папки или общий список входящих |
| Справа | письмо: тема, отправитель, текст, вложения |

- **Все входящие** — письма из папок «Входящие» всех ящиков.
- Нажмите на название ящика, чтобы увидеть только его входящие.
- Непрочитанные помечены точкой и жирным шрифтом, флажок — звёздочкой.
- «Другие папки» — папки сверх стандартных; открытие папки запускает её синхронизацию.

## Чтение письма

- Внешние картинки заблокированы. Кнопка **«Показать»** над письмом загружает их
  для этого письма (в целях приватности).
- Вложение можно открыть кликом; опасные типы (exe, bat, ps1 и т.п.) блокируются
  политикой безопасности.
- Письмо открывается в изолированной области: скрипты и формы внутри письма не работают.

## Написание и ответ

- **Написать** — кнопка вверху или клавиша `C`.
- **Ответить** — `R`, **ответить всем** — `A`, **переслать** — `F`.
- `Ctrl+Enter` — отправить. `Esc` — закрыть редактор.
- Вложить файл — скрепка внизу редактора (до 20 МБ на файл).
- Если несколько ящиков, отправителя можно выбрать в верхней части редактора.

Копия отправленного письма сохраняется в «Отправленные»; при обрыве связи письмо
уходит в очередь и отправляется после восстановления соединения.

## Поиск

Поле поиска — вверху окна, горячая клавиша `/`.
Ищет по теме, отправителю, получателям и тексту загруженных писем. Поиск выполняется
локально по кешу, работает без сети.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `C` | новое письмо |
| `R` | ответить |
| `A` | ответить всем |
| `F` | переслать |
| `/` | поиск |
| `J` / `K` | следующее / предыдущее письмо |
| `S` | поставить/снять флажок |
| `Delete` | удалить (в корзину) |
| `Esc` | закрыть письмо/редактор/настройки |
| `F5` | проверить почту |

## Офлайн

GG Email продолжает работать без сети: список и уже открытые письма доступны,
прочитанные письма остаются в кеше. Новые письма загрузятся, когда соединение вернётся.

## Настройки

- **Учётные записи** — список ящиков, удаление, добавление (если разрешено администратором).
- **Интерфейс** — тёмная/светлая тема, плотность списка.
- **Политики** — какие настройки управляются организацией и какие значения заданы.
- **Обновления** — версия, канал, проверка обновлений.
- **О программе** — версии компонентов, папка данных, очистка локального кеша.

Очистка кеша не затрагивает письма на сервере: после неё они загрузятся заново.

## Частые вопросы

**Почему письма в папке появились не сразу?**
Синхронизируются стандартные папки; остальные — при открытии. Нажмите `F5`
или иконку обновления.

**Почему не приходят письма от Gmail?**
Gmail требует пароль приложения (при включённой 2FA) или OAuth. Обратитесь в ИТ-отдел.

**Куда сохраняются данные?**
`%APPDATA%\GG Email` — база, вложения, логи. Пароли хранятся зашифрованными средствами Windows.

**Можно ли работать с несколькими ящиками одновременно?**
Да, каждый ящик синхронизируется независимо, «Все входящие» собирает их вместе.

**Что делать при ошибке «Нет соединения»?**
Проверьте сеть/VPN. Клиент сам переподключится; статус виден внизу окна.
