# Политики GG Email (ADMX/ADML)

Файлы в этом каталоге генерируются из `src/shared/policy-catalog.json`:

```powershell
npm run admx
```

## Установка

```powershell
# локально (нужны права администратора)
.\Install-GGEmailADMX.ps1 -Backup

# или в центральном хранилище домена
\\domain\sysvol\domain\Policies\PolicyDefinitions
```

После установки откройте `gpedit.msc` → Административные шаблоны → **GG Email Почта**.
В домене используется `gpmc.msc`; шаблоны подхватываются из Central Store.

## Ветки реестра

| Ветка | Назначение | Приоритет |
|---|---|---|
| `HKLM\SOFTWARE\Policies\GG Email` | машинная политика (GPO компьютера) | выше |
| `HKCU\SOFTWARE\Policies\GG Email` | пользовательская политика (GPO пользователя) | ниже |

Клиент читает обе ветки, машинное значение побеждает. Некорректные значения
игнорируются и попадают в диагностику (раздел «Политики» в настройках).

## Справочник политик

| Политика | Значение реестра | Тип | По умолчанию | Описание |
|---|---|---|---|---|
| URL автонастройки во внутренней сети | `AutoconfigUrl` | string | `` | Базовый URL автонастройки в формате Thunderbird (например https://autoconfig.example.com/mail/config-v1.1.xml?emailaddress=%EMAIL%). Клиент обращается к нему раньше публичных источников. |
| Предустановленные учётные записи (JSON) | `PreconfiguredAccounts` | string | `` | JSON-массив шаблонов учётных записей, предлагаемых при первом запуске. Пароли в политике не хранятся: пользователь вводит их один раз. |
| Разрешить пользователям добавлять и изменять учётные записи | `AllowAccountManagement` | boolean | Включено | Если отключено, список учётных записей фиксируется политикой, а редактор скрывается. |
| Разрешить вход через OAuth2 | `AllowOAuth` | boolean | Включено | Включает OAuth2 для Gmail и Яндекс, если настроены client_id. |
| Google OAuth client ID | `GoogleClientId` | string | `` | Client ID корпоративного приложения, зарегистрированного в Google Cloud (тип Desktop app). |
| Yandex OAuth client ID | `YandexClientId` | string | `` | Client ID приложения, зарегистрированного в Яндекс ID. |
| Режим обновлений | `UpdateMode` | enum | `auto` | auto — скачивать и устанавливать тихо при выходе; notify — скачивать и спрашивать пользователя; disabled — не проверять обновления. |
| Канал обновлений | `UpdateChannel` | enum | `stable` | Канал выпусков, за которым следует клиент. |
| URL сервера обновлений | `UpdateBaseUrl` | string | `` | Переопределяет встроенный источник обновлений (generic provider). Пусто — использовать источник по умолчанию. |
| Интервал проверки обновлений, часы | `UpdateCheckIntervalHours` | number | `6` | Как часто клиент проверяет обновления. Минимум 1 час, максимум 168 часов (7 дней). |
| Отсрочка обновлений, дни | `UpdateDeferDays` | number | `0` | Задерживать установку новой версии на указанное число дней. 0 — устанавливать сразу. |
| Блокировать внешний контент в письмах | `BlockRemoteContent` | boolean | Включено | Блокирует картинки, стили и трекинг-пиксели из интернета до явного разрешения пользователя. |
| Отображать HTML-письма | `AllowHtmlMail` | boolean | Включено | Если отключено, показывается только текстовая часть письма. |
| Заблокированные расширения вложений | `BlockedAttachmentExtensions` | multistring | `exe, …` | Список расширений через запятую, которые нельзя открыть или сохранить из письма. |
| Требовать шифрованные соединения | `RequireTls` | boolean | Включено | Запрещает незашифрованные подключения IMAP/SMTP; учётные записи с security=none отклоняются. |
| Максимальный размер кеша, МБ | `MaxCacheSizeMb` | number | `4096` | Мягкий лимит локального кеша писем; первыми вытесняются самые старые тела писем. |
| Хранить заголовки писем, дни | `CacheRetentionDays` | number | `365` | Заголовки старше указанного срока удаляются из локального кеша; письма остаются на сервере. |
| Интервал фоновой синхронизации, минуты | `SyncIntervalMinutes` | number | `5` | Резервный интервал опроса, если IMAP IDLE недоступен. |
| Язык интерфейса | `DefaultLanguage` | enum | `auto` | auto — использовать язык Windows. |
| Показывать баннер «управляется организацией» | `ShowPolicyBanner` | boolean | Включено | Показывает уведомление, если хотя бы одна настройка управляется групповой политикой. |
| Уровень логирования | `LogLevel` | enum | `warn` | Подробность локальных логов. Логи не содержат паролей и тел писем. |
| Разрешить телеметрию диагностики | `TelemetryEnabled` | boolean | Отключено | Отправляет анонимные счётчики сбоев и производительности на настроенный сервер. По умолчанию выключено. |

## Быстрая проверка без домена

```powershell
.\Test-Policy.ps1            # записать тестовые значения в HKCU
.\Test-Policy.ps1 -Remove    # удалить
```

## Рекомендованный набор для компании

| Политика | Значение | Зачем |
|---|---|---|
| `AutoconfigUrl` | `https://autoconfig.company.ru/mail/config-v1.1.xml?emailaddress=%EMAIL%` | пользователь вводит только адрес и пароль |
| `AllowAccountManagement` | Отключено | фиксированный список ящиков |
| `UpdateMode` | `auto` | обновления без участия пользователя |
| `UpdateChannel` | `stable` | только стабильные выпуски |
| `UpdateDeferDays` | `2` | откат «плохого» релиза до массовой установки |
| `BlockRemoteContent` | Включено | защита от трекеров |
| `RequireTls` | Включено | запрет открытых соединений |
| `MaxCacheSizeMb` | `2048` | предсказуемый размер кеша |
